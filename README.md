# Built-In Self-Test System with Self Healing
•	Designed a Memory Built-In-Self-Test (MBIST) module in Verilog for FPGA BRAM, using address/data generators and a golden-signature comparator for automated fault detection & address reallocation. 

•	Built a self-checking testbench that runs MBIST autonomously and validates PASS/FAIL status against a golden signature no manual waveform inspection required. 

•	Verified fault coverage through multiple fault injections (stuck-at, bit-flip, memory errors), confirming signature mismatches correctly flag induced faults.
